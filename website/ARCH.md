# Website sources

`index.html` is the landing template; `scripts/site.mjs` renders it into `docs/index.html` with the benchmark data, the MongoDB comparison charts and the code examples, and renders the Markdown guides. `make dev` serves the generated `docs/` directory, and a static web server can serve it from a subdirectory. The website includes local fonts, the selected defuss-shadcn 0.9.14 components, ECharts and their notices in `docs/assets/vendor/`; the npm package excludes website assets.

The code shown on the page lives in `examples/`. `make lint` typechecks the TypeScript files against `src/`, and `scripts/site.mjs` highlights them at build time, so the page cannot show code that does not compile. Setup installs the package from npm.

The comparison charts draw the medians in `docs/benchmarks/mongodb-*.json`. `scripts/check-site.mjs` checks that the data embedded in the page equals `mongoChartData()` of those reports, and that every claim in the scale section still holds for them. Why two charts beat one table: VERIFIED: the medians span 0.015 ms to 4.5 s, so one shared axis would hide the short operations; the first chart shows relative speed on a log2 scale, the second each operation on its own linear scale.

`demo/` holds Ledger, the playground the landing page embeds in a same-origin frame; its own [ARCH.md](demo/ARCH.md) covers its design. The frame loads lazily, because the first visit writes about 120 MB to the browser's origin private file system (VERIFIED: 113.1 MiB committed after the seed, shown in the playground's header). The frame follows the site's theme through the storage event, so the landing page needs no protocol for it.

The Database Explorer section embeds `database-explorer/`, defuss-shadcn's Database Explorer, which `scripts/shadcn-sync.mjs` copies into `docs/` from defuss-shadcn's build; this repository has no source for it. It runs defuss-db in its own OPFS worker under the namespace `strata`, apart from Ledger's `defuss-db-demo`, so Ledger's Reset data leaves it alone (VERIFIED: both namespaces, and Ledger's reset deleting only its own, in the sources 2026-11-22). Its first visit writes about 24 MB (VERIFIED: 22.8 MiB in OPFS once the app was ready, Chromium, 2026-11-22).

The explorer reads no stored theme, so `assets/site.js` sets the site's theme in the frame from outside, as the explorer's own light/dark switch does, when the frame loads and on every theme change; opened in a tab of its own, it follows the system preference. VERIFIED: the site e2e switches the theme and reloads with a stored theme that differs from the system's, and fails when either hook is removed.

`application/app-api-docs.html` is the API reference app, defuss-shadcn's API Documentation scaffold adapted to a library. The scaffold documents a web API: an API key, API versions, curl samples and a server to call. The page keeps the scaffold's layout, navigation, search, Call it form and code listings, and drops those parts and its German translation. Copying it unchanged, as the explorer is copied, would document the scaffold's example workspace instead of defuss-db.

`scripts/api-docs.mjs` writes the app's content. The guides are the sections of `docs/API.md`; the reference lists every member its method tables describe, with the signature from the type declarations the package ships. The build fails when a table names a member the declarations lack, or when a public method of `Database`, `Collection` or `ReadCollection` has no row, so the reference cannot drift from either. Call it runs a member on a sample database in the page's memory: defuss-db from `dist/`, bundled with `application/sample.mjs` into `js/api-docs/client.js`. `application/sample.mjs` holds the sample, each member's starting arguments, and why 12 members cannot run in a page. VERIFIED: the site e2e sends the example of each of the other 59 members on a fresh sample and fails on any error.

Like the scaffold, the page loads defuss-dom-router and defuss-search from jsDelivr, Shiki from esm.sh and lucide from unpkg. Once the page is idle it also loads a search-by-meaning model from Hugging Face and ONNX Runtime from jsDelivr, 4.6 MB by the scaffold's count; with the data saver on, the search stays on keywords and skips the download. The human chose to keep these loads on 2026-11-22. Privacy: those hosts see each visitor's address and what the page requests, while the Database Explorer and Ledger load nothing from another origin. The app reads and writes the site's stored theme (`defuss-db-theme`), so a switch in the app or on the landing page carries over to the other.
